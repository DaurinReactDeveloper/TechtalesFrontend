<h1>📚 TechTales – Historias y Aprendizajes sobre Tecnología y Desarrollo</h1>

<h2>🖼️ Descripción del Proyecto (Frontend)</h2>
<p>
    El frontend de <strong>TechTales</strong> está desarrollado en <strong>React.js</strong> con <strong>Vite</strong>, ofreciendo un rendimiento rápido y una experiencia 
    de usuario fluida. Diseñado en <strong>Figma</strong> y construido con un enfoque <strong>100% responsivo</strong>, permite a los usuarios explorar historias inspiradoras, 
    participar en retos técnicos, y conectarse con la comunidad a través de comentarios y reacciones.
</p>

<h2>🚀 Funcionalidades Clave</h2>
<ul>
    <li>🏠 <strong>Inicio</strong>: Página de bienvenida e introducción a la plataforma.</li>
    <li>🎯 <strong>Retos</strong>: Clasificados en Básicos, Intermedios y Avanzados. Los usuarios pueden marcarlos como completados.</li>
    <li>📖 <strong>Historias</strong>: Los usuarios pueden explorar historias compartidas, dar <strong>like/dislike</strong> y <strong>comentar</strong>.</li>
    <li>📝 <strong>Registrarse / Iniciar Sesión</strong>: Registro tradicional o mediante <strong>Google Login (Firebase Auth)</strong>.</li>
    <li>🔐 <strong>Inicio de Sesión Administrador</strong>: Sección exclusiva para gestión interna.</li>
    <li>👤 <strong>Sección Usuario</strong>: Visualiza sus historias publicadas y retos completados.</li>
    <li>🛠 <strong>Sección Administrador</strong>: Listado, edición y eliminación de usuarios y retos.</li>
</ul>

<h2>🔗 Tecnologías y Herramientas Utilizadas</h2>
<ul>
    <li>⚛️ <strong>React.js</strong> con <strong>Vite</strong> para un desarrollo ágil y rápido.</li>
    <li>🧭 <strong>React Router DOM</strong> para una navegación fluida entre páginas.</li>
    <li>📡 <strong>Axios</strong> para el consumo de la API RESTful.</li>
    <li>🔐 <strong>Firebase Auth</strong> para autenticación con Google.</li>
    <li>🔓 <strong>jwt-decode</strong> para decodificar y gestionar JWTs en el frontend.</li>
    <li>✨ <strong>AOS (Animate on Scroll)</strong> para animaciones suaves en el scroll.</li>
    <li>⭐ <strong>React Icons</strong> para íconos modernos e intuitivos.</li>
    <li>📱 <strong>Diseño responsivo</strong> para adaptarse a móviles, tablets y escritorio.</li>
    <li>🎨 <strong>Diseño UI/UX</strong> hecho en <strong>Figma</strong>.</li>
</ul>

<h2>📡 Comunicación con la API</h2>
<p>
    Todo el contenido dinámico (retos, historias, usuarios, sesiones) es gestionado mediante peticiones HTTPS a la API RESTful desarrollada en .NET 8. 
    La autenticación se maneja con JWTs y los tokens se decodifican en el cliente con <strong>jwt-decode</strong>.
</p>
<p>
    🔗 <strong>API Documentada en Swagger:</strong> 
    <a href="https://techtalesapi.runasp.net/index.html" target="_blank">https://techtalesapi.runasp.net/index.html</a>
</p>
